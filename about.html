About Live HoneyPot

Live HoneyPot is a security monitoring project built around an internet-facing T-Pot honeypot.

The project collects real-world attack telemetry, analyzes suspicious activity, and explores practical security operations workflows including detection engineering, investigation, and SIEM monitoring.

Architecture

The project follows a lightweight security telemetry pipeline:

Internet Attack Traffic
          |
          v
     T-Pot Honeypot
          |
          v
 Elasticsearch / ELK
          |
          +--> Investigation
          |
          +--> Detection Engineering
          |
          v
  Public Telemetry Dashboard

Objectives

  • Practice security monitoring and incident investigation
  • Analyze attacker behavior using real telemetry
  • Build detection engineering workflows
  • Develop security automation tools
  • Explore practical SIEM operations
