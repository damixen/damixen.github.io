# GingerPot

A security telemetry dashboard built around honeypot data, ELK, and detection engineering.

Live demo:
https://gingerpot.damixen.com

## Features

- Live telemetry dashboard
- Honeypot activity visualization
- Security event analysis
- Detection engineering research

## Architecture

|
Elasticsearch
|
Telemetry Export
|
DigitalOcean Functions
|
Public Dashboard
