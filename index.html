What is GingerPot?

GingerPot is a security engineering project that operates an internet-facing T-Pot honeypot and publishes summarized telemetry through a lightweight serverless platform.

Rather than exposing Elasticsearch directly, telemetry is exported as lightweight JSON reports and served through a DigitalOcean Functions API.

Current Focus

Building practical security skills through operating internet-facing honeypots, investigating telemetry, and developing detection logic.
